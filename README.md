# FINEX — Save · Pay · Grow

**FINEX** is a mobile-first Nigerian digital wallet and financial services platform.

Send money, pay bills, buy airtime & data, and manage your finances in one place.

Built with **HTML5, CSS3, and vanilla JavaScript**. No backend required for the current version. Data is stored locally in the browser so the app works offline after the first visit.

---

## Features

- Secure registration & login
- Dashboard with live balance and quick actions
- Wallet: fund & withdraw
- Instant transfers to any Nigerian bank
- Bill payments: Electricity, Cable TV, Internet, Airtime, Data
- Full transaction history with filters
- Profile, security & notification settings
- Responsive design (mobile bottom nav + desktop sidebar)
- Progressive Web App (installable on Android)
